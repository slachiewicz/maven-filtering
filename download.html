Download Apache Maven Filtering 3.5.2-SNAPSHOT Source

Apache Maven Filtering 3.5.2-SNAPSHOT is distributed in source format. Use a source archive if you intend to build Apache Maven Filtering yourself. Otherwise, simply use the ready-made binary artifacts from central repository.

You will be prompted for a mirror - if the file is not found on yours, please be patient, as it may take 24 hours to reach all mirrors.

In order to guard against corrupted downloads/installations, it is highly recommended to verify the signature of the release bundles against the public KEYS used by the Apache Maven developers.

Apache Maven Filtering is distributed under the Apache License, version 2.0.

We strongly encourage our users to configure a Maven repository mirror closer to their location, please read How to Use Mirrors for Repositories.
